Merchandise Insights Tool
Merchandise Insights Tool supports our team’s internal product research by reviewing publicly available Etsy product information to understand market directions before developing new items.

Scope and Access
Through the Etsy Open API, the tool retrieves listing titles, displayed prices, keywords, materials, product images, and basic shop information; access is read-only and excludes private seller details, payments, orders, customer messages, and confidential account data.

Internal Use Only
The application is restricted to company use, with no public access or paid subscriptions, and cannot publish, edit, manage, or delete Etsy listings.

Project Status
Testing and development are ongoing, and available API functions may be adjusted according to Etsy’s approval, technical limitations, and authorized access.

Independence
Etsy is a name owned by Etsy, Inc.; this internal project has no affiliation with, endorsement from, sponsorship by, or official certification from Etsy, Inc.
